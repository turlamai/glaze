## Item 4 — Migration from the 0.x legacy facade proven in HackDigest

Proven. HackDigest commit
[`2a2199a`](https://github.com/turlamai/hackdigest/commit/2a2199a)
(2026-10-25, "refactor(backend): import explicit glaze modules instead of
the legacy facade") moved the backend onto `glaze/app`, `glaze/api`,
`api-macros`, `browser`, `events`, `path`, `sys`, `types`, `window-state`
with 0.17.0 semantics unchanged, closing glaze's G3-S3 consumer item. The
commit is an ancestor of HackDigest `v0.4.0` (verified by merge-base), so
the v0.4.0 release run exercised the migrated backend through the full
packaged-native matrix on every platform. HackDigest pins `glaze v0.18.0`
in both CI and release workflows.
